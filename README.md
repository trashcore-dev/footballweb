# ⚽ Football League Dashboard

A simple web dashboard that displays football league results, standings, and upcoming fixtures using the [football-data.org](https://www.football-data.org/) API.

---

## 🚀 Features
- Browse **leagues** (TIER_ONE competitions).
- View **league standings**.
- See **upcoming fixtures** (next 10 matches).
- Lightweight HTML/CSS/JS project.

---

## 🔑 Setup

1. Get a free API key from [football-data.org](https://www.football-data.org/).
2. Clone this repository:
