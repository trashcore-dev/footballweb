# Products on Sale Website

A simple responsive website that displays products on sale with their prices. Each product is shown in a card format with an image, name, and price.

## Features

- Responsive layout using Flexbox
- Product cards with image, name, and price
- Hover effect on product cards
- Clean and minimal design
- Easy to add new products

## Installation

1. Clone this repository:
    ```bash
    git clone https://github.com/your-username/products-on-sale.git
    ```
2. Navigate to the project folder:
    ```bash
    cd products-on-sale
    ```
3. Open `index.html` in your browser:
    ```bash
    open index.html
    ```

## Usage

- To add a new product, duplicate one of the existing product cards in `index.html` and update the image, name, and price.
- Customize styling in `index.html` inside the `<style>` tag or add an external CSS file.
